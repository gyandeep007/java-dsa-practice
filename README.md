
# Java DSA Practice

A structured Java repository for Data Structures
and Algorithms practice, focused on MAANG-level
technical interviews.

## Technology Stack

- Java 17
- Maven
- JUnit 5
- IntelliJ IDEA

## Project Structure

- src/main/java: DSA implementations
- src/test/java: JUnit test cases

## Running Tests

Run all tests:

```bash
mvn clean test
```

## Goals

- Implement data structures from scratch.
- Understand internal memory representation.
- Analyze time and space complexity.
- Write comprehensive JUnit tests.
- Practice interview-level problems.
